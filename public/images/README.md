# 📸 Photo Setup

Drop your 5 photos here with these exact filenames:

| File | Page |
|------|------|
| `photo-1.jpg` | Page 1 — "The beginning of everything" |
| `photo-2.jpg` | Page 2 — "Somewhere between reckless and brave" |
| `photo-3.jpg` | Page 3 — "The ones who make you laugh the hardest" |
| `photo-4.jpg` | Page 4 — "Still becoming" |
| `photo-5.jpg` | Page 5 — Final page |

Then in `src/data/pages.js`, update each `imageSrc: null` to `imageSrc: "/images/photo-N.jpg"`.

**Best results:**
- Portrait orientation (3:4 ratio) works best for the layout
- JPEG, WebP, or PNG
- Aim for 800–1200px tall for retina sharpness without bloat
