# 🎵 Audio Setup

Drop a cinematic ambient track here named `ambient.mp3` (or `.ogg`).

**Recommendations:**
- Lo-fi instrumental, 128–192kbps, 3–10 minutes, loop-friendly (no hard start/end)
- Good free sources: Free Music Archive, ccMixter, Pixabay Music

Once the file is placed here, the film-reel toggle (top-right corner of the site) will activate it.

The track plays at 25% volume and loops silently. It will only begin after the user clicks the icon — no autoplay.
